# 🏎️ AirWheel — 허공 핸들 레이싱

맥북(또는 웹캠 달린 PC) 웹캠으로 **양손을 인식**해, 보이지 않는 핸들을 허공에서 돌려 운전하는
**MediaPipe + Three.js 기반 3D 웹 레이싱 게임**입니다. 설치 없이 브라우저에서 바로 실행됩니다.

## 🎮 조작법

| 동작 | 조작 |
|------|------|
| 🖐️🖐️ **양손을 웹캠에 보이기** | 핸들 잡기 (주행 시작) |
| 🎡 **양손을 핸들처럼 기울이기** | 좌/우 조향 (두 손을 잇는 선의 각도) |
| ✊ **두 손 주먹 쥐기** | 가속 (꽉 쥘수록 빠르게) |
| ✋ **두 손 펴기** | 감속(코스트) |
| 🙌 **양손을 위로 높이 들기** | 브레이크 |

> 차량·장애물을 피해 최대한 멀리 달리세요. 충돌하면 게임 오버, 최고 기록은 자동 저장됩니다.

키보드 폴백(웹캠 테스트용): `←` `→` 조향 · `↑` 가속 · `↓` 브레이크

## 🚀 실행

웹캠 접근은 `https` 또는 `localhost`에서만 허용되므로 **로컬 서버**로 열어야 합니다.

```bash
# 방법 1 (Node)
npm start            # http://localhost:8080

# 방법 2 (Python)
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속 → **"웹캠 켜고 시작"** 클릭 → 카메라 권한 허용.

## 🧩 구조

```
index.html   레이아웃 · import map(three / mediapipe CDN) · HUD
styles.css   네온 UI · 웹캠 미리보기 · 핸들 인디케이터
hands.js     MediaPipe HandLandmarker → 조향/스로틀/브레이크 추출 (저역통과 필터)
game.js      Three.js 무한 레이싱 (도로·차량·장애물·충돌·카메라)
main.js      게임 루프 · HUD 업데이트 · 입력 연결 · 키보드 폴백
```

## ⚙️ 기술

- **손 추적**: `@mediapipe/tasks-vision` HandLandmarker (양손 21 랜드마크, GPU 델리게이트)
- **렌더링**: Three.js (그림자, 안개, 그라데이션 스카이, 세그먼트 재활용 무한 도로)
- **조향 원리**: 두 손바닥 중심을 잇는 선의 `atan2` 각도 → ±34°에서 풀 조향
- 모든 영상 처리는 **브라우저 안에서만** 수행되며 서버로 전송되지 않습니다.

## 📌 요구사항
